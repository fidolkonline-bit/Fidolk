Fido LK test run

    Try the new system before the shop uses it

    This is a practice run of a few ordinary shop days: stock arrives, you sell, customers pay later, things come back, phones go in for repair, staff get paid. Each step tells you what to do and what the system should do. Where there is a rupee amount, work it out on paper too. If the system’s number is different from yours, that is exactly what we need to know.

    It’s a practice copyNothing you do here touches the real shop, its stock or its money. Make mistakes freely.
    Mark each stepPress Works or Problem. A problem opens a box: write what you saw in your own words.
    “It should stop you”Some steps try something the shop should never allow. Those work when the system refuses.
    When you finishThe list at the bottom collects every problem with your notes. Copy it and send it to your developer.
